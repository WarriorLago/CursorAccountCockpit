功能说明

从账号总览到账单导出、会话与设置

以下配图均来自应用真实界面（演示数据脱敏），便于公开文档展示。

1. 账号列表

列表视图适合宽屏巡检：邮箱、套餐、用量与操作同一行完整可见。

2. 账号卡片

卡片视图快速浏览多账号状态，标签、备注与用量明细一目了然。

3. 官方账单 / 收据

选账号与起止月份，按状态筛选后批量导出 Stripe 原版 PDF。

4. 会话管理

只读读取本机 Agent 会话，支持搜索、多选与 Markdown 导出。

5. 设置

Cursor 路径、托盘行为、账单导出并行数、语言，以及自动更新开关。

账号与额度

所有账号在一个地方。列表适合宽屏巡检，卡片适合快速扫一眼。

  • 显示套餐、总用量、Auto 和 API 用量、按量付费和重置时间
  • OAuth、Token / JSON、读取本机登录三种导入方式
  • 一键切号：写入登录信息、重启 Cursor，再确认切换生效；授权失效的账号会被拦下
  • 跨设备备份会自动跳过失效账号

用量洞察

回答三个问题：钱花在哪、什么时候花的、哪个模型最贵。

  • API 额度、Auto 额度、按量付费和其他分开统计，并和官方百分比核对
  • 每日趋势与用量时刻表联动，点击可定位到当天或某个小时的请求
  • 工作时间、节假日和调休可配置，能看非工作时间的用量占比
  • 账号对比、模型排行、耗尽预测，以及导出 CSV
  • 只保存元数据，不读取对话；后台同步和提醒都默认关闭

团队网关

把账号池变成 OpenAI / Anthropic / Responses 兼容的 API，给程序或同事使用。默认只监听本机，局域网访问需要手动开启。

  • 每人一个 Key：每日和每分钟限额、可用模型、到期日，可随时停用或删除
  • 按 Key、账号、模型统计请求量和来源 IP；Token 为估算值，真实费用以用量洞察为准
  • 账号出错自动切换，忙时排队，账号池改动立即生效
  • 提供试用面板和接入示例，包括 cURL、Python、Node.js、Anthropic SDK 和 Claude Code
  • 局域网访问走不加密的 HTTP，只适合可信网络
  • 连续对话优先复用账号与会话；工具权限、工作目录和代理连接可单独设置

鹈鹕测试

同一句提示词发给多个模型，让它们各自生成一个 HTML，在沙箱里并排比较。预览时禁止联网。

  • 账号和模型自由搭配，实时显示每一格的进度
  • 打分、盲评、排行榜，失败项可换账号重试，单项结果可移除
  • 存档可复用，可导出成一个 HTML 文件分享
  • 每个账号用独立的隔离 Worker，不影响正在运行的 API 服务

账单与收据

按账号、月份和状态筛选，批量下载官方 PDF，完成后生成统计文本，方便核对。

  • 按账号隔离，支持跨月和跨年
  • 并行数可调，默认 5 路

本机会话

只读浏览这台电脑上的 Cursor Agent 对话，不改动 Cursor 的任何数据。

  • 按标题、项目、会话 ID 和正文全文搜索
  • 多选后导出 Markdown，可选是否包含工具调用

设置

常规、更新和用量洞察分开管理，不常用的选项默认收起。

  • Cursor 路径自动识别，窗口和托盘行为、语言可调
  • 工作时间、节假日、后台同步、提醒规则和数据保留

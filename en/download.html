Windows

Windows 10 / 11 x64 with WebView2, which is usually already installed. The portable build needs no installer and unpacks locally on first run.

macOS

Account and quota features work out of the box. The API service and pelican bench also need Node.js 20+ and the official Cursor Agent CLI. The DMG is ad-hoc signed and not notarized, so the first launch may need approval in System Settings → Privacy & Security.

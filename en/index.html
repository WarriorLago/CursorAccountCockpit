Accounts and quota

Know which account is running out without logging in to each

Every account's plan, usage and reset time in one table. Switching writes the login, restarts Cursor and then confirms the switch actually took effect.

  • Import through OAuth, a token or the local Cursor login
  • Tags, notes, search and bulk actions
  • Accounts with expired authorization are flagged and never switched to
Usage insights

Quota going fast? See where it actually went

Cost is split into API quota, Auto quota and real charges, then checked against Cursor's own percentages, so you can see at a glance what actually reaches your bill.

  • Daily trend and a time map by real date. Click a day to see its requests
  • Configurable working hours, with China public holidays and make-up days one click away
  • See which models cost most and how long the quota should last
Team gateway

Stop handing out tokens. Give everyone a key

Turn the account pool into a local API compatible with OpenAI, Anthropic and Responses. Each key is metered and limited on its own, and when someone leaves you simply disable theirs.

  • Daily and per-minute limits, allowed models and expiry dates
  • Requests and source IPs by key, account and model
  • Automatic failover between accounts and restarts for exited workers
Pelican bench

Which model is better? Ask them all to draw

One prompt goes to many models, the results render side by side in a sandbox, and your scores feed a leaderboard. Blind mode reveals the model only after you score it.

All of these are real model output for “draw a pelican riding a bicycle”.

Where your data goes

Account credentials are the most sensitive thing here, so it is spelled out.

Account credentialsEncrypted in the local data folder and only used to call Cursor's own services
Usage recordsOnly time, model, tokens and cost, never conversations. Retention is configurable and you can clear it at any time
Gateway logsOnly key, source IP, model, status and latency, never prompts or answers
Network requestsCursor's services, Stripe invoice files and GitHub updates. Holiday data is fetched only when you ask
Data sent to the authorNone. This project has no servers of its own

Questions

Is this an official Cursor product?

No. It is an independent tool, and some of the endpoints it uses are internal ones that Cursor's own web and desktop apps rely on, so a change at Cursor can require an update here.

Does it cost anything?

The tool is free under CC BY-NC-SA 4.0, for non-commercial use. Cursor's subscription and usage are billed by Cursor.

Are the amounts on the usage page real spending?

Mostly not. Amounts within quota are the equivalent value Cursor deducts from your allowance. Only on-demand usage is a real charge, and the page shows it separately.

Can it tell how many people use an account?

Not when a login is shared directly, because Cursor offers no reliable data for that. If everyone uses their own gateway key, you can see usage and source IPs per key. These figures describe usage, not any person's conduct.

Is it risky to share an account?

It can be. Sharing an account or routing through a gateway may not comply with Cursor's terms and can trigger risk controls, so please judge this for yourself. Teams using it long term should consider Cursor's team plans.

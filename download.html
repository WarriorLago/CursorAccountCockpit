Windows

支持 Windows 10 / 11 x64，需要 WebView2（系统通常已自带）。便携版不用安装，首次运行会解压到本机。

macOS

账号与额度可以直接用。API 服务和鹈鹕测试需要先装 Node.js 20+ 和官方 Cursor Agent CLI。DMG 使用临时签名，没有经过 Apple 公证，首次打开可能要到“系统设置 → 隐私与安全性”里允许。
